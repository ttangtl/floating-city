# 海上浮城

末日海上建城经营的手机网页游戏（Vite + TypeScript + Canvas，等距视角，美术全部程序化绘制，零运行时依赖）。

## 玩法
- 洪水之后，带着幸存者在木筏上重建家园
- 捕鱼台、海水提取厂、打捞站、漂木站产出原料；厨房、织布坊、熔炼炉加工
- 建筑头上冒黄色图标就点一下收获；幸存者每分钟都要吃鱼餐、喝淡水，吃饱喝足士气才会涨、才会有新人来
- 帐篷决定人口，人口决定有多少工人；指挥塔等级决定其他建筑上限和解锁
- 扩建木筏、完成补给订单赚金币、跟着主线任务推进
- 离线最多补算 2 小时产出

## 运行
```
npm install
npm run dev      # 手机连同一 WiFi，打开终端里的 Network 地址
npm run share    # 生成单文件版：分享/海上浮城.html
```

## 改数值
所有资源、建筑、任务、消耗速度都在 `src/data.ts`。
